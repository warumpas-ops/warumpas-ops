# 📟 The BlackBerry 10 Renaissance Suite

A collection of standalone, physical-keyboard-optimized applications and tools engineered for BlackBerry 10 devices (Q5, Q10, Classic Q20, Passport).

| Project | Description | Target Hardware |
|---|---|---|
| **[QCyberdeck](https://github.com/warumpas-ops/qcyberdeck)** | Full Linux terminal cyberdeck with CRT phosphors & canonical Ubuntu ASCII art suite | Q5 / Q10 / Classic |
| **[PodBB](https://github.com/warumpas-ops/podbb)** | Native podcast aggregator & player built for physical navigation | Q5 / Q10 / Passport |
| **[NoteVault](https://github.com/warumpas-ops/notevault-bb10)** | Minimalist monotone note-taking vault with SD card sync & Space Grotesk font | Q5 / Q10 / Classic |
| **[WhatsBB](https://github.com/warumpas-ops/whatsbb)** | Native WhatsApp client with companion Node.js multi-device bridge | BlackBerry 10 |
| **[Cosmos](https://github.com/warumpas-ops/cosmos-bb10)** | 1-bit retro celestial smart alarm clock with planetary tracking | 720×720 LCD |
| **[BBType](https://github.com/warumpas-ops/bbtype)** | Physical keyboard typing speed & accuracy benchmark (Monkeytype client) | Q5 / Q10 / Classic |
| **[Kiwix BB10](https://github.com/warumpas-ops/kiwix-bb10)** | Offline Wikipedia & ZIM archive reader for distraction-free research | BlackBerry 10 |
| **[FocusTimer](https://github.com/warumpas-ops/focustimer-bb10)** | Minimalist Pomodoro & focus timer with tactile keyboard shortcuts | BlackBerry 10 |
