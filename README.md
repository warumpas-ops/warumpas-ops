# 📟 The BlackBerry 10 Renaissance Suite

A collection of standalone, physical-keyboard-optimized applications and tools engineered for BlackBerry 10 devices (Q5, Q10, Classic Q20, Passport).

| Project | Description |
|---|---|
| **[QCyberdeck](https://github.com/warumpas-ops/qcyberdeck)** | Full Linux terminal cyberdeck with CRT phosphors & canonical Ubuntu ASCII art suite |
| **[PodBB](https://github.com/warumpas-ops/podbb)** | Native podcast aggregator & player built for physical navigation |
| **[NoteVault](https://github.com/warumpas-ops/notevault-bb10)** | Minimalist monotone note-taking vault with SD card sync & Space Grotesk font |
| **[WhatsBB](https://github.com/warumpas-ops/whatsbb)** | Native WhatsApp client with companion Node.js multi-device bridge |
| **[Cosmos](https://github.com/warumpas-ops/cosmos-bb10)** | 1-bit retro celestial smart alarm clock with planetary tracking |
| **[BBType](https://github.com/warumpas-ops/bbtype)** | Physical keyboard typing speed & accuracy benchmark (Monkeytype client) |
| **[Kiwix BB10](https://github.com/warumpas-ops/kiwix-bb10)** | Offline Wikipedia & ZIM archive reader for distraction-free research |
| **[FocusTimer](https://github.com/warumpas-ops/focustimer-bb10)** | Minimalist Pomodoro & focus timer with tactile keyboard shortcuts |
